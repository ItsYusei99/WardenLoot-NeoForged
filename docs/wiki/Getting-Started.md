# Getting Started

## Requirements

- Minecraft **1.21.1** with **NeoForge 21.1.249**.
- **Curios API 9.5.1+1.21.1** installed on the client and dedicated server.
- The same WardenLoot NeoForged JAR on both sides.

## Installation

1. Install NeoForge for Minecraft 1.21.1.
2. Install Curios API in the client's and server's `mods/` folders.
3. Copy `wardenlootforge-1.1.3-neoforge-1.21.1.jar` into both `mods/` folders.
4. Start the client and server.

Curios is required for the Warden Ears accessory. NeoForge will stop loading the mod if the dependency is missing.
