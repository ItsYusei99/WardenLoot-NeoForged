# Items and Materials

| In-game name | ID | Purpose |
|---|---|---|
| Consumed Soul | `wardenlootforge:sculk_soul` | Crafting ingredient for Imbued Ingots; also used by other recipes. |
| Imbued Ingot | `wardenlootforge:sculk_ingot` | Smithing material for tools and several armor pieces. Fire-resistant. |
| Warden Heart | `wardenlootforge:warden_heart` | Used to craft the Heartplate and Warden Blood. Uncommon rarity. |
| Warden Blood | `wardenlootforge:warden_blood` | Drink for temporary effects or use in the smithing table to recharge a Still Heartplate. One recipe yields four bottles. |

## Consumed Soul

Besides being a crafting ingredient, a Consumed Soul can drop when mining sculk or from Warden-related loot. See [Loot and Progression](Loot-and-Progression.md) for the chances.

## Warden Heart

When Warden armor features are enabled, the Warden loot modifier adds one Warden Heart. It can also be crafted from Imbued Ingots, echo shards, and a diamond. Use it for the Heartplate and Warden Blood.

## Warden Blood

Warden Blood uses a drinking animation. Consuming it grants these effects for 60 seconds:

- Blindness.
- Strength IV.
- Echolocation.

The Echolocation effect enables the sound-based detection described in [Curios and Echolocation](Curios-and-Echolocation.md).
