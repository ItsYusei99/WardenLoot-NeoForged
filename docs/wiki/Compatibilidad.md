# Compatibilidad y límites conocidos

- Soporte probado: Minecraft **1.21.1** con **NeoForge 21.1.249**.
- Curios API **9.5.1+1.21.1** es requerido en cliente y servidor para Warden Tendrils.
- Instala el mismo JAR en ambos lados.
- El mod conserva el ID `wardenlootforge`; no instales otra copia del Warden Loot Forge original junto a este port.
- Otras versiones de Minecraft y NeoForge aún no están soportadas. El repositorio está nombrado para poder añadir ports separados después.
- Los valores de estadísticas que se fijan durante el registro usan los defaults si la config COMMON todavía no se ha cargado; ver [Configuración](Configuracion.md).

El servidor fue probado en NeoForge 21.1.249 con Curios y el loot de Warden. Las versiones futuras deberán validarse por separado antes de marcarse como compatibles.
