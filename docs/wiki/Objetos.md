# Objetos y materiales

| Nombre del juego | ID | Para qué sirve |
|---|---|---|
| Consumed Soul | `wardenlootforge:sculk_soul` | Material para fabricar Imbued Ingots. Puede caer de sculk y de loot relacionado con Warden. |
| Imbued Ingot | `wardenlootforge:sculk_ingot` | Material de herrería para herramientas y varias piezas de armadura. Es resistente al fuego. |
| Warden Heart | `wardenlootforge:warden_heart` | Se usa para fabricar el Heartplate y Warden Blood. Tiene rareza poco común. |
| Warden Blood | `wardenlootforge:warden_blood` | Se bebe para obtener efectos temporales y se usa para recargar un Still Heartplate. Una receta produce cuatro botellas. |

## Consumed Soul

Además de ser un ingrediente, una Consumed Soul puede caer al minar bloques de sculk o en los loot modifiers de Warden. La probabilidad de cada fuente se explica en [Loot y progresión](Loot-y-progresion.md).

## Warden Heart

El loot modifier añade un Warden Heart garantizado al Warden si está habilitado el Heartplate o el resto de armadura. También se puede fabricar con Imbued Ingots, echo shards y un diamante. Se necesita para el Heartplate y para preparar Warden Blood.

## Warden Blood

Warden Blood tiene animación de bebida. Al consumirlo aplica durante 60 segundos:

- Ceguera.
- Fuerza IV.
- Ecolocalización.

El efecto de ecolocalización también activa la detección por vibraciones descrita en [Curios y ecolocalización](Ecolocalizacion-y-Curios.md).
